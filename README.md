##### 2023/6/5补充
### 项目初始化（在 Mac intel芯片运行下列命令时，需要加sudo修饰，意思是拥有管理员权限）
cnpm 版本8.3.0
npm 版本8.16.0
node 版本16.14.0


```
npm i cnpm@8.3.0 -g
cnpm i electron-builder -g
cnpm i electron -g 
cnpm i
```

npm run electron:serve
